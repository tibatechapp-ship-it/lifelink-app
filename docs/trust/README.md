# حزمة ثقة المشغّل — LifeLink

> خارطة المنتَجة — أسبوع 2. هذه الحزمة للجهة التي تشغّل LifeLink (بنك دم، مركز
> نقل، مبادرة طلابية): تشرح ما يجمعه النظام فعلاً وما لا يجمعه إطلاقاً، كم
> يُحتفظ بكل شيء، ومن المسؤول عن ماذا. كل بند هنا مأخوذ من الكود نفسه —
> ليس وعداً مستقبلياً.

| الوثيقة | ماذا تجد فيها |
|---|---|
| [سياسة البيانات](data-policy.md) | ما نجمعه حقل-بحقل، وما **لا نجمعه** إطلاقاً (قسم إلزامي)، وأين يُشفَّر |
| [الاحتفاظ والحذف](retention.md) | كم يبقى كل نوع بيانات، وكيف يُحذف نهائياً |
| [تقييم أثر الحماية (DPIA مبسطة)](dpia.md) | المخاطر، ضوابطها المطبقة في الكود، والمخاطر المتبقية بصدق |
| [مسؤوليات المشغّل](operator-responsibilities.md) | ما يجب ضبطه قبل التشغيل، ونظافة السجلات، وخطة الحوادث |

**النطاق**: يغطي هذا التوثيق خادم LifeLink (`app.py` + `routes/` + `models/`)
بإصداره الحالي. أي ميزة جديدة تُغيّر ما يُجمَع يجب أن تُحدّث هذه الحزمة في
نفس الـPR — والاختبار `tests/test_trust_pack.py` يفشل إن اختلّت الروابط أو
غاب القسم الإلزامي.
