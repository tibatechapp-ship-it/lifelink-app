# سياسة البيانات — ما نجمعه وما لا نجمعه

> مرجع الحقول: `models/models.py` و`routes/` في هذا المستودع. ما لم يُذكر
> هنا لا يجمعه النظام — والالتزام بالنفي أقوى من الالتزام بالجمع.

## ما نجمعه (وفقط)

### حساب المتبرع (`Donor`)
| الحقل | التشفير أثناء التخزين | لماذا |
|---|---|---|
| الاسم | **نعم — Fernet** (`FIELD_ENCRYPTION_KEY`) | عرض الملف الشخصي |
| البريد الإلكتروني | لا (مُفهرس للدخول ومنع التكرار) | تسجيل الدخول |
| الهاتف | **نعم — Fernet** | تواصل عند النداء المطابق |
| المدينة | **نعم — Fernet** | مطابقة محلية |
| الفصيلة، العمر، الوزن | لا | شرط صلاحية التبرع والمطابقة |
| إحداثيات اختيارية (خط عرض/طول) | لا — اختيارية بالكامل، والمطابقة تعمل بلاها بالمدينة | مطابقة جغرافية أدق |
| آخر تبرع + متاح/غير متاح | لا | منع النداء على متبرع لم يمرّ عليه 56 يوماً |
| كلمة المرور | **هاش** (لا تُخزَّن نصاً أبداً) | المصادقة |

### نداء الطوارئ (`EmergencyRequest`)
| الحقل | التشفير أثناء التخزين |
|---|---|
| اسم المريض | **نعم — Fernet** |
| المستشفى | **نعم — Fernet** |
| هاتف التواصل | **نعم — Fernet** |
| الفصيلة، عدد الوحدات، المدينة، الأولوية، الحالة، الملاحظات | لا |
| إحداثيات اختيارية | لا |

### بيانات تشغيلية
- **رموز الدخول**: موقّعة بصلاحية 24 ساعة (و7 أيام للتحديث) — ليست مخزنة في قاعدة البيانات.
- **محدد المعدل**: عدّاد في الذاكرة لكل IP، يُمسح تلقائياً كل 60 ثانية — لا يُكتب في أي مكان.
- **السجلات**: Flask بلا سجلات استعلام تحتوي أسماء أو هواتف؛ لا نجمع IP في قاعدة البيانات.

## ما لا نجمعه — إطلاقاً

1. **لا هوية وطنية ولا أرقام شخصية حكومية** — لا حقل لذلك في أي جدول.
2. **لا تاريخ ميلاد** — يكفي العمر كعدد سنوات لشرط الصلاحية.
3. **لا تتبع موقع مستمر (GPS خلفي)** — الإحداثيات اختيارية يدوية لحظة النداء فقط، ولا يُطلب تشغيل تحديد الموقع.
4. **لا ملفات صحية أو تحاليل أو تاريخ مرضي** — فقط الفصيلة والعمر والوزن وآخر تبرع.
5. **لا بيانات دفع أو بطاقات** — النظام بلا أي ميزة دفع.
6. **لا بيانات بيومترية ولا صور** — لا رفع صور في أي مسار.
7. **لا محادثات أو رسائل بين المستخدمين** — النظام نداءات فقط، لا دردشة.
8. **لا كوكيز تتبع ولا إحصاءات طرف ثالث ولا إعلانات** — لا سكربتات تحليلات في القوالب.
9. **لا قوائم جهات اتصال ولا قراءة جهاز** — لا شيء من المتصفح/الهاتف غير ما تكتبه أنت.
10. **لا مشاركة ولا بيع لبيانات مع أي طرف خارجي** — القاعدة: البيانات في قاعدة مشغّلك، لا تخرج منها.

## من يرى ماذا (تُطبّقه الشيفرة، لا الترجمة الطيبة)

- **زائر مجهول**: عدّاد عام فقط (`/api/stats`) — أرقام مجاميع بلا أي أسماء أو هواتف، وقائمة النداءات المفتوحة ببيانات الاتصال **مشفّرة في القاعدة** وتُعرض للنداء العام بقدر الحاجة (فصيلة/مستشفى/مدينة/هاتف تواصل) لأن بلا هاتف لا نداء.
- **متبرع**: يعدّل ملفه فقط (`id == current.id`).
- **مركز/مستشفى**: يدير النداءات، يرى المتبرعين بلا حذف.
- **مشغّل (admin)**: إدارة كاملة + `/admin/stats` (مجاميع إحصائية: نداءات، فصائل، زمن استجابة متوسط — **أرقام لا بيانات تعريفية**).

## الحقوق

- **الحذف**: انظر [retention.md](retention.md) — حذف نهائي فوري عند الطلب.
